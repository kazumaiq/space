# ORBITAL: BEYOND

Браузерный 3D космический симулятор на базе **React + TypeScript + Vite + Three.js / React Three Fiber + Zustand**.

## Основные возможности

- **3D Космодром и стартовая площадка**: стартовый стол, башня обслуживания, ангар VAB, башня управления, криогенные резервуары и активная ракета.
- **Модульный конструктор ракет (VAB)**: 15 типов деталей (капсулы, спутники, баки S/M/L, ЖРД, вакуумные двигатели, боковые ускорители SRB, разделители ступеней, обтекатели, парашюты, посадочные опоры, солнечные панели, батареи, научный отсек) с расчётом массы, тяги, TWR и Delta-V по формуле Циолковского.
- **Физика полёта и орбитальная механика**: двойная точность (`Float64`), гравитация, экспоненциальная атмосфера и сопротивление, расход топлива, разделение ступеней с физическими обломками, SAS (`STABILITY / PROGRADE / RETROGRADE`), переходы между сферами влияния (SOI) Земли, Луны и Марса.
- **Орбитальная карта и Web Worker**: расчёт прогноза траектории методом Рунге–Кутты 4-го порядка в отдельном потоке с отображением апогея (`Ap`), перигея (`Pe`) и перехвата Луны.
- **Прогрессия и сохранения**: 9 контрактов, дерево технологий, исследование поверхности с планетоходом и сбором образцов, несколько слотов сохранений в IndexedDB и адаптер для Supabase.

## Запуск

```bash
npm install
npm run dev
```

## Управление в полёте

- `W / S` — тангаж
- `A / D` — рыскание
- `Q / E` — крен
- `Shift / Ctrl` — управление тягой (`Z` — 100%, `X` — 0%)
- `Space` — зажигание и разделение ступеней
- `T` — переключение режимов SAS
- `P` — парашют, `G` — посадочные опоры, `L` — солнечные панели
- `M` — орбитальная карта
- Мышь + колёсико — вращение и приближение камеры
